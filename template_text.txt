  CHAPTER 1 
INTRODUCTION 
Small and Medium Enterprises (SMEs) and Micro, Small and Medium Enterprises (MSMEs) form the 
backbone of many economies, contributing significantly to employment, innovation, and GDP. However, these 
businesses often face challenges in accessing advanced an alytical tools for data -driven decision-making due to 
limited resources, technical expertise, and high costs associated with traditional business intelligence solutions. 
This capstone project addresses this gap by developing a Generative AI Agent tailored for SME/MSME business 
insights. 
 
 
The Gap:  
SMEs/MSMEs typically lack the financial and human resources to hire dedicated analysts or invest in 
expensive software for market analysis, customer insights, and financial decision support. Traditional tools are 
often too complex, costly, or require specialized skills, leaving owners reliant on intuition or basic spreadsheets. 
This results in suboptimal decisions, missed opportunities for cost savings, and inefficient resource allocation, 
particularly in areas like inventory management, sales optimization, and strategic planning. 
 
The Goal : 
The primary objective of this project is to empower SME/MSME owners with an accessible, AI -driven 
virtual business consultant. The Generative AI Agent will leverage Retrieval-Augmented Generation (RAG) and 
prompt-based reasoning to provide actionable insights from business data. Key functionalities include answering 
queries on sales and expenses, generating financial summaries (e.g., profit/loss trends), and suggesting strategies 
for cost reduction, inventory optimization, and sales growth. By using open -source technologies, the solution 
remains cost -effective and scalable across sectors such as retail, manufacturing, and services, while offering 
hands-on learning for students and professors in AI, RAG, and agent workflows.

MODULE DESCRIPTION 
 
The Generative AI Agent for SME/MSME Business Insights is structured into six key modules, each handling a 
specific aspect of the system's functionality. These modules work together to transform raw business data into 
actionable insights, enabling SME/MSME owners to make informed decisions without advanced technical skills. 
The Data Ingestion and Embedding Module serves as the foundation, loading CSV data and converting it into 
embeddings stored in ChromaDB. This allows for efficient retrieval of relevant information during queries. 
The RAG Module enhances response accuracy by retrieving contextually similar data chunks and feeding them 
into the LLM, ensuring answers are grounded in the actual business data. 
The Analytics and Computation Module  provides direct, structured calculations like profits and summaries, 
offering quick insights for common business questions. 
The Agent Orchestration Module acts as the brain, using LangChain to coordinate tools and generate dynamic 
responses, making the system adaptable to various query types. 
The User Interface Module  delivers a user -friendly Gradio -based chatbot, incorporating features like quick 
queries, feedback, and file uploads to improve interaction. 
Finally, the Tool Integration Module defines specialized tools that the agent can invoke, such as calculators and 
recommenders, enabling complex reasoning and strategy suggestions. 
Together, these modules create a cohesive pipeline from data input to user output, leveraging open -source AI 
technologies to democratize business analytics for SMEs/MSMEs. 
 
 
Architectural Foundation: 
 
The Generative AI Agent for SME/MSME Business Insights is built on a modular architecture leveraging open -
source technologies to ensure scalability, cost-effectiveness, and ease of deployment. At its core is the LangChain 
framework, which orchestrates the agent workflow, integrating Retrieval -Augmented Generation (RAG) for 
context-aware responses. The system uses ChromaDB as the vector database for efficient storage and retrieval of 
embeddings, generated via sentence -transformers/all-MiniLM-L6-v2. The Large  Language Model (LLM) is 
powered by Llama-3, accessed through Ollama for local inference, ensuring data privacy and offline capability. 
Data is sourced from CSV files containing SME/MSME financial metrics, processed into text chunks for 
embedding. The fron tend is implemented with Gradio, providing an intuitive chatbot interface for user 
interactions. 
 

=== PAGE 6 ===
 
 
 
Functional Modules: 
 
The system comprises several interconnected functional modules: 
● Data Ingestion and Embedding Module : Handles loading of CSV data, chunking into text 
representations, and generating embeddings for storage in ChromaDB. 
● Retrieval-Augmented Generation (RAG) Module: Retrieves relevant data chunks based on user queries 
and augments LLM prompts with contextual information for accurate responses. 
● Analytics and Computation Module : Performs calculations for profits, summaries, and trends using 
pandas for data manipulation and custom functions for business logic. 
● Agent Orchestration Module: Utilizes LangChain agents to coordinate multiple tools, enabling dynamic 
query handling and strategy generation. 
● User Interface Module: A Gradio-based chatbot with features like quick queries, response length control, 
file uploads, feedback mechanisms, and random question suggestions. 
● Tool Integration Module : Defines specialized tools for financial querying, summary generation, and 
recommendation engines, integrated into the agent workflow. 
 
 
 
Operational Flow: 
 
The operational flow begins with data preparation, where CSV files are embedded into ChromaDB. Upon user 
query via the Gradio interface, the agent parses the input and selects appropriate tools. For RAG -based queries, 
relevant embeddings are retrieved and passed to the LLM for response generation. Predefined analytics functions 
handle specific calculations, while the agent combines insights for comprehensive answers. Responses are 
displayed in the UI, with options for feedback and further interaction. The s ystem supports iterative refinement, 
allowing users to upload additional context or adjust query parameters for enhanced insights.

ARCHITECTURAL DIAGRAM 
 
4.1 Overview: 
The architecture of the Generative AI Agent for SME/MSME Business Insights follows a modular, layered design 
that separates data processing, AI reasoning, analytics computation, and user interaction. This ensures scalability, 
maintainability, and ease of updates. The system is built entirely with open-source technologies and runs locally, 
eliminating dependency on cloud services for core functionality.

4.3 Layer Descriptions 
4.3.1 User Interface Layer 
● Component: Gradio-based web interface 
● Functionality: Provides interactive chatbot, quick query dropdown, response controls, file upload, 
feedback buttons, and random question generator 
● Technology: Gradio (Python library for web UIs) 
● Purpose: Enables non-technical users to interact with the AI agent through a user-friendly web interface 
4.3.2 Application Layer 
● Component: AI Agent orchestration 
● Functionality: Coordinates between RAG pipeline, analytics functions, and user inputs; handles 
predefined queries and dynamic Q&A 
● Technology: LangChain framework 
● Purpose: Acts as the central controller, routing queries to appropriate processing components 
4.3.3 Processing Layer 
● Component: RAG Pipeline and Analytics Engine 
● Functionality: 
○ RAG: Retrieves relevant data chunks, augments prompts, generates responses 
○ Analytics: Computes profits, summaries, strategies from structured data 
● Technology: LangChain RetrievalQA, Pandas for data manipulation 
● Purpose: Performs core AI reasoning and data analysis tasks 
4.3.4 Data Layer 
● Component: Vector Store and Raw Data 
● Functionality: Stores embedded text representations for fast retrieval; maintains original CSV data for 
analytics 
● Technology: ChromaDB (vector database), CSV files 
● Purpose: Provides persistent, searchable storage for business data 
4.3.5 Infrastructure Layer 
● Component: AI Models and Embeddings 
● Functionality: Provides LLM for text generation, embedding model for vectorization 
● Technology: Ollama (Llama3), HuggingFace sentence-transformers 
● Purpose: Supplies the foundational AI capabilities for understanding and generating human-like 
responses 

=== PAGE 9 ===
 
 
4.4 Data Flow 
1. User submits query via Gradio interface 
2. Application layer routes query to appropriate handler (RAG or analytics) 
3. For RAG: Query embedded → Vector search in ChromaDB → Relevant chunks retrieved → 
Augmented prompt sent to Llama3 → Response generated 
4. For analytics: Direct computation on CSV data → Structured response formatted 
5. Response returned to user interface and displayed 
4.5 Key Design Decisions 
● Modular Design: Each layer is independent, allowing for easy replacement or enhancement of 
components 
● Local Execution: All processing occurs on user's machine, ensuring data privacy and reducing latency 
● Open-Source Stack: Maximizes accessibility and minimizes costs 
● Hybrid Approach: Combines RAG for flexible queries with structured analytics for precise calculations 
● Scalable Storage: Vector database supports efficient retrieval even as data volume grows

def load_data(csv_path: str = "data/sme_data_large.csv") -> pd.DataFrame: 
    p = Path(csv_path) 
    if not p.exists(): 
        base = Path(__file__).resolve().parent.parent 
        p = (base / csv_path) 
    if not p.exists(): 
        raise FileNotFoundError(f"CSV not found at {csv_path} or {p}") 
    df = pd.read_csv(p) 
    return df

    row = df[df[COL_MONTH].str.lower() == month_label.lower()]

df[COL_MONTH].str.contains(month_label.split('-')[-1], case=False, na=False)] 
    if row.empty:

def summary_q1_2023(df: pd.DataFrame) -> Dict[str, object]: 
    q1_months = ['Jan-23', 'Feb-23', 'Mar-23'] 
    q1_df = df[df[COL_MONTH].isin(q1_months)] 
    if q1_df.empty: 
        return {"found": False} 
    total_sales = int(q1_df[COL_SALES].sum()) 
    total_expenses = int(q1_df[COL_EXPENSES].sum()) 
    avg_customers = int(q1_df[COL_CUSTOMERS].mean()) 
    net_profit = total_sales - total_expenses 
    profit_margin_percent = round((net_profit / total_sales) * 100, 2) if total_sales > 0 else 0 
    return {"found": True, "total_sales": total_sales, "total_expenses": total_expenses, "avg_customers": 
avg_customers, "net_profit": net_profit, "profit_margin_percent": profit_margin_percent}
